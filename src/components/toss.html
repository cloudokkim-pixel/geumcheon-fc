토스오더 테이블주문 사용 조건

1) 토스포스+프론트 사용 매장

토스포스에서 테이블주문 신청하기

현재 기준! 1셋트(QR 20개) 무료 이벤트를 진행하고 있어요. 이후 추가로 필요할 경우에는 스마트스토어에서 구매 가능해요.
1.
토스포스 왼쪽 상단 ≡ → 테이블주문 메뉴를 눌러주세요.
2.
동의하고 테이블QR스티커 무료 신청하기를 눌러주세요.
3.
색상, 연락처, 주소를 입력 후 신청하기를 눌러주세요.
a.
영업일 기준 14:00 이전 신청 시 당일 출고
b.
휴일 및 공휴일 신청 시 다음 영업일에 출고
4.
입력 정보를 확인하고 동의하고 신청하기를 눌러 주세요.
5.
테이블 주문(QR) 최초 신청 시 보증금 결제가 진행되어요.
6.
생성된 QR을 촬영해서 보증금 결제를 진행하시면 신청 완료!
a.
테이블 주문(QR)을 수령하신 후 등록하여 최초 사용하시면 결제하신 보증금이 환급되어요.

토스오더 테이블주문 셋팅 방법

1. 카테고리 등록하는 방법

1.
토스포스 왼쪽 상단 ≡ → 테이블주문 메뉴를 눌러 주세요.
2.
카테고리 → + 카테고리 추가 를 선택해 주세요.
3.
원하시는 카테고리명을 입력 후 저장 버튼을 눌러 주세요.
4.
고객용 채널 노출 버튼을 활성화해주세요.
고객용 채널이란? 키오스크, 테이블주문 등 매장 손님이 직접 보시게 되는 주문 화면을 의미해요.

2. 카테고리 노출 순서 변경

1.
토스포스 카테고리 노출 순서 변경도 가능해요.
토스포스 → 왼쪽 상단 ≡ → 토스오더 테이블주문 → 카테고리에서 상단의 순서 편집 버튼을 클릭해주세요.
2.
노출 순서를 변경하 싶은 카테고리를 클릭해요.
3.
위로 또는 아래로 를 클릭해 순서를 변경할 수 있어요.
4.
저장 버튼을 클릭해주세요

3. 상품 등록하는 방법

1.
토스포스에서 상품을 등록할 수 있어요.
토스포스 왼쪽 상단 ≡ → 테이블주문 → 상품에서 우측 상단 +상품 추가 버튼을 클릭해 주세요.
2.
테이블주문 화면에 노출할 상품명, 상품설명, 이미지를 추가하고 등록 버튼을 눌러 주세요.
3.
카테고리 순서 편집과 동일하게 상품 순서도 변경 가능해요.
사장님용 포스 화면과 매장 손님용 고객 채널에서 보이는 상품 순서를 각각 다르게 설정할 수 있어요.
4.
위로 또는 아래로 를 클릭해 순서를 바꿔주신 후 저장 버튼을 꼭 눌러 주세요.

4. 테이블주문에 노출할 상품 이름, 이미지, 설명 등록하는 세부 방법

1.
토스포스에서 테이블주문에 노출할 상품명, 이미지, 상품 설명을 추가할 수 있어요.
2.
스크롤을 내리면 상품 태그 설정도 가능해요. 없음 , 인기 , 신규 중에 원하시는 것을 선택 후 확인 버튼을 꼭 눌러 주세요.

5. 상품 삭제하는 방법

1.
토스오더 테이블 주문에서도 상품을 삭제 또는 품절/품절해제 등록을 할 수 있어요.
토스포스 왼쪽 상단 ≡ → 테이블주문 → 상품에서 상단의 전체 삭제/품절 버튼을 클릭해 주세요.
?
해당 설정은 테이블 주문 뿐만 아니라 토스 포스 상품에도 영향이 갈 수 있으니 꼭 주의해 주세요!
2.
삭제 또는 품절/품절해제를 원하는 상품의 옆 체크박스를 눌러 주세요.
체크가 된 상태에서 삭제 , 품절 , 품절해제 버튼을 눌러 주세요.
3.
삭제가 된 상품은 복구할 수 없으니 신중하게 진행해 주세요.

6. 상품별 추가 옵션 등록/수정하는 방법

1.
토스포스에서 옵션을 등록/수정할 수 있어요.
토스포스 쪽 상단 ≡ → 테이블주문 → 옵션에서 상단의 +옵션 추가 버튼을 클릭해 주세요.
2.
옵션 추가 시, 필요 항목을 세부적으로 설정하고 등록할 수 있어요.
3.
카테고리 순서 편집과 동일하게 옵션 순서도 변경 가능해요.
위로 또는 아래로 를 클릭해 순서를 바꿔주신 후 저장 버튼을 꼭 눌러 주세요.

7. 원산지 등록하기

1.
토스포스 왼쪽 상단 ≡ → 기타설정 → 원산지 표기를 눌러 주세요. 원산지 표기 설정 내용은 테이블주문 QR 화면 최하단에 표기돼요.

8. 테이블 연동하기

1.
토스포스 왼쪽 상단 ≡ → 테이블주문 → 설정 → 테이블 연동하기를 눌러주세요.
2.
QR스티커에 있는 고유번호를 입력해 주세요.
3.
포스에 설정해놓은 테이블과 QR코드에 기재된 번호를 선택하여 연동해 주신 후 상단의 저장 버튼을 꼭 눌러 주세요.
3.
추가 구매가 필요할 경우, QR 코드 설정 >을 누르신 후 추가 QR 구매하기 > 를 눌러 주문 해주세요.

손님 주문 모바일 화면

1. 메인 화면 및 메뉴 상세 화면

1.
손님께서 QR코드 촬영 후 첫 진입 화면에서 메뉴판을 확인하실 수 있어요. 메뉴판에서 주문을 원하는 상품을 선택한 후 아래 담기 버튼을 누르시면 장바구니에 담을 수 있어요.

2. 메뉴 담기

2.
여러명이 동시에 QR코드 접속이 가능하고, 원하는 상품을 담은 후 장바구니에서 담은 상품을 확인할 수 있어요. 모두 상품을 담았다면 주문하기 버튼을 눌러서 주문을 완료해요. 만약, 추가 주문이 필요하다면 메뉴판으로 버튼을 눌러 주시면 되어요.

3. 포스에서 주문내역 확인 및 주문서 재출력 방법

1.
토스 POS의 테이블 홈 화면에서 테이블 주문건을 확인하실 수 있어요. 주문서에는 주문번호가 테- 양식으로 확인 되어요.
2.
주문서 재출력이 필요하신 경우 토스 POS 상단의 재출력 버튼을 눌러 주세요. 주문서 출력을 원하는 테이블을 선택해 주신 후 출력할 영수증을 선택해 주세요.

주문 알림음 설정

손님이 테이블 주문 QR로 주문하면, 포스 기기에서 소리가 나요
1.
토스포스 왼쪽 상단 ≡ → 테이블주문 → 주문 알림→ 주문 알림음 · 직원 호출음을 누르면 설정을 하실 수 있어요. 연결된 포스마다 주문 알림을 끄거나 켤 수 있어요.
2.
알림음 소리 종류 및 알림음의 반복 횟수도 설정이 가능해요.
3.
직원호출 알림도 설정하실 수 있어요. 진행하신 후 상단의 저장 버튼을 꼭 눌러 주세요.

직원호출

1.
토스포스 왼쪽 상단 ≡ → 테이블주문 → 직원호출 → 직원호출 사용 버튼 ON 설정을 해요.
손님이 자주 호출하는 사유를, 옵션명으로 작성 후 추가하면 대응이 편해져요.
2.
손님이 QR코드 인식 후 모바일로 직원호출을 눌러 [물티슈] 옵션을 선택하고 호출하기를 누르면, 직원호출 시 알림이 포스 상단에 표시되고, 확인 후 X를 누르면 노란색 표시는 사라져요.
3.
토스포스 우측상단 손바닥 표시를 누르면, 과거 호출 내역을 확인할 수 있어요.

주문 알림효과

1.
토스포스 왼쪽 상단 ≡ → 테이블주문 → 주문 알림 → 주문 알림 → 주문 알림효과 버튼을 활성화 해주세요.
2.
주문이 들어오면 테이블이 깜박거리고 클릭을 한번이라도 해야 깜박임이 없어져요. 확인하기 전에는 테이블 홈 옆에 숫자 이 떠있어요. 깜박임 효과를 영상으로 확인해보세요!

네이버 리뷰 이벤트

1.
토스포스 왼쪽 상단 ≡ → 테이블주문 → 네이버 리뷰 이벤트를 눌러서 설정해 주세요.
2.
손님이 보는 화면에서는 이렇게 노출 되어요.

선불형 테이블주문 사용하기

유의사항

1. 테이블주문하면서 선불결제도 가능하도록 오픈되었어요!
?
선불결제 : 손님이 QR을 찍어 휴대폰으로 결제하면 주문이 들어가는 방식
?
후불결제 : 손님이 QR로 주문하고, 결제는 나갈 때 카운터에서 하는 방식
2.
오프라인 카드결제수수료와 동일한 수수료가 나가고 추가 수수료가 전혀 없어요. (※ PG가 아닌, VAN수수료 발생)
3.
토스페이, 네이버페이, 카카오페이, 앱카드(신한 / 국민 / 현대 / 하나 / 우리 / 삼성)로 결제 가능해요.
a.
핸드폰으로 결제하고 싶지 않을 경우에는 '나갈 때 직접 결제하기'를 선택할 수 있어요.
b.
현금, 실물카드, 분할결제가 필요한 경우에는 후불로 나갈 때 계산만 가능해요.
4.
테이블주문 선불결제는 아직 포인트/스탬프/쿠폰/선불권 적립 및 사용을 할 수 없어요.
5.
테이블주문 선불결제를 쓰기 위해 포스를 후불에서 선불로 바꾸는 것이 아니에요. 선불포스에서는 아직 테이블오더를 쓸 수 없어요.

선불결제 테이블오더 신청하기

1.
토스포스 왼쪽 상단 ≡ → 테이블주문 → 설정 → 선·후불 결제 방식 순서로 진행해요.
테이블주문 메뉴 진입점이 없다면, 토스포스 왼쪽 상단 ≡ → 매장 페이지 → 업종유형 변경 → 후불형 선택 후 확인이 필요해요.
2.
선불결제를 이용해 볼 수 있어요.
a.
간편결제인 페이 및 앱카드 결제만 가능해요. (추후 다양한 결제수단 추가 예정)
b.
나갈 때 결제할 수 있는, 나갈 때 결제 버튼을 노출/비노출 여부를 직접 선택 할 수 있어요.
4.
선불결제를 신청하면 신청확인은 플레이스에서 진행하고, 1영업일에서 최대 2주까지 걸릴 수 있어요.
5.
신청 확인이 되면 카카오 알림톡으로 대표자에게 안내해드려요.
6.
선불결제 확인중으로 보이면 아직 신청 확인중인 상태에요.
7.
선불결제 신청 승인이 완료되면 대표자 번호로 알림톡이 발송돼요.

모바일 결제 화면

1.
토스페이, 네이버페이, 앱카드로 결제 가능해요. (※ 카카오페이 및 카드사 도입 준비중)
2.
테이블오더 선불결제는 베타서비스로 아직 포인트, 스탬프, 쿠폰 적립과 사용을 할 수 없어요.
